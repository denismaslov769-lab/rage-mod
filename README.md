# rage-mod

MoonLoader-скрипт для **SA-MP** с меню в стиле популярного CS2-софта: тёмная тема, боковая панель с вкладками, группбоксы, анимированные тумблеры, акцентный цвет и оверлей-виджеты.

## Активация
- Команда в чате: `/ragemd`
- Или горячая клавиша (по умолчанию **Insert**, меняется во вкладке «Меню»)

## Вкладки
| Вкладка | Что внутри |
| --- | --- |
| Мир | Клиентское время (слайдеры, пресеты), клиентская погода (выпадающий список) |
| Виджеты | Watermark (ник / FPS / пинг / время), инфо-панель (HP/броня с прогресс-барами, координаты, скорость), список активных функций, часы, уведомления |
| Меню | Выбор акцентного цвета + пресеты, скругление, прозрачность, анимации, клавиша открытия |
| Разное | Очистка чата, копирование координат, тест уведомлений, перезагрузка/выгрузка скрипта |
| Конфиг | Сохранение / загрузка / сброс (`moonloader/config/rage-mod.ini`) |

Виджеты можно перетаскивать мышкой, пока открыто меню.

## Используемые виджеты ImGui
Toggle (кастомный, с анимацией), Checkbox, RadioButton, SliderInt, SliderFloat, Combo, ColorEdit4, InputText, Button, ProgressBar, Tooltip, Child-группбоксы, кастомные кнопки вкладок.

## Установка
1. Установите **MoonLoader**, **SAMPFUNCS** и библиотеку **mimgui**.
2. Положите `rage-mod.lua` в папку `moonloader`.
3. Зайдите в игру и введите `/ragemd`.
